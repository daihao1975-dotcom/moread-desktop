# 墨阅 MoRead 隐私说明

墨阅是完全离线运行的本地软件。

- **不联网**：不包含任何统计、遥测、广告、自动更新检查或账号功能，不向任何服务器发送数据。「检查更新」只会在系统浏览器中打开发布页面，墨阅本身不发起网络连接。文档中的远程图片与资源默认不加载；只有在你主动点按链接时，才会交由系统浏览器或邮件程序打开。
- **不上传、不收集**：文档内容只在你的电脑上读取和保存。
- **本机保存的内容**：保存阅读偏好（主题、字号、正文宽度、正文字体、分栏比例、侧边栏开关、界面语言）、窗口大小，以及侧边栏逻辑分类的名称、层级、折叠状态和文件路径引用（`library.json`）。macOS 位于 `~/Library/Application Support/MoRead/` 及应用的 WebKit 本地存储；Windows 位于 `%AppData%\MoRead\` 及 WebView2 本地存储。不保存文档正文，分类索引中的路径仅用于恢复侧边栏，不上传；「记住最近打开的文件」默认关闭，只有你在阅读设置中开启后，才会在上述设置文件中保存最近 10 个文件与文件夹的路径，关闭即清空。
- **文件访问**：只读取你通过打开文件、打开文件夹、拖入或系统「打开方式」明确选择的文件，以及这些文件在本机分类索引中保留的引用；文档内的相对链接与图片不能越出你打开的文件夹。
- **文档中的代码不会执行**：脚本与危险 HTML 会被移除，阅读区运行在隔离的沙箱中。

删除上述偏好文件夹即可清除墨阅在本机保存的全部设置。

# MoRead Privacy Statement

MoRead runs entirely offline. It has no analytics, telemetry, advertising, automatic update checks or accounts, and sends no data to any server. **Check for Updates** only opens the release page in your browser; MoRead itself makes no connection. Remote images and resources in documents are not loaded; links open in your browser or mail app only when you click them. Document contents are read and saved only on your computer. MoRead stores reading preferences (theme, font size, text width, split ratio, sidebar, language) and the window size, plus logical folder names, hierarchy, collapsed states and file path references in a local `library.json` — on macOS in `~/Library/Application Support/MoRead/` and the app's WebKit storage, on Windows in `%AppData%\MoRead\` and WebView2 storage — never document text. Library paths restore the sidebar and are never uploaded. Recent file and folder paths (up to 10) are stored there only if you turn on **Remember recent files** in Reading settings; it is off by default and turning it off clears the list. It reads only files you explicitly open, drop or open with it, including references retained in the local library index, and relative links and images cannot reach outside the folder you opened. Scripts in documents never run; the reading pane is sandboxed. Delete the preference folder to remove every setting.
