墨阅 MoRead 1.0.10 · Windows 安装说明

1. 将本文件夹放到任意位置，双击 MoRead.exe 运行，无需安装。
2. 首次运行如出现 SmartScreen 提示，点按「更多信息 → 仍要运行」。
3. 需要 Microsoft Edge WebView2 运行时（Windows 11 及已更新的 Windows 10 已自带）。
4. 完整说明见同目录《使用手册.md》。

系统要求：Windows 10 / 11，64 位。

MoRead 1.0.10 · Windows installation

1. Put this folder anywhere and double-click MoRead.exe. No installation is needed.
2. If SmartScreen appears on first run, click More info → Run anyway.
3. Microsoft Edge WebView2 Runtime is required (included in Windows 11 and up-to-date Windows 10).
4. See User-Guide.md for details.

Requires 64-bit Windows 10 or 11.
