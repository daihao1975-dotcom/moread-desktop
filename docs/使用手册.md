# 墨阅 MoRead 使用手册

版本 1.0.6 · 适用于 macOS 12 及以上（Apple 芯片）与 Windows 10 / 11（64 位）

墨阅是一款离线的 Markdown 阅读与轻编辑工具。文档只在本机读取和保存，不联网、不上传，也不会自动运行文档里的脚本。

## 1. 安装

### macOS

1. 打开 `MoRead-1.0.6-macOS-arm64.dmg`，把「MoRead」拖入「应用程序」。
2. 首次打开时，如系统提示无法验证开发者：在「应用程序」中按住 Control 点按 MoRead，选择「打开」；若仍被阻止，前往「系统设置 → 隐私与安全性」，在页面下方点按「仍要打开」。此操作只需一次。
3. 如需用墨阅打开所有 Markdown 文件：在访达中选中任意 `.md` 文件 →「显示简介」→「打开方式」选择 MoRead →「全部更改」。

### Windows

1. 运行 `MoRead-1.0.6-Windows-x64.exe`，无需安装；可放在任意文件夹并创建桌面快捷方式。
2. 需要 Microsoft Edge WebView2 运行时（Windows 11 与已更新的 Windows 10 已自带）。缺少时程序会提示并退出，可从微软官网下载安装。
3. 首次运行如出现 SmartScreen 提示，点按「更多信息 → 仍要运行」。

## 2. 打开文档

| 方式 | 说明 |
| --- | --- |
| 打开文件 | 工具栏或 ⌘ / Ctrl + O，可多选 |
| 打开文件夹 | 列出文件夹（含子文件夹）中的全部 Markdown，最多 2000 篇；在其他程序中新建、改名或删除的文件，回到墨阅窗口时会自动更新列表 |
| 拖入 | 把文件或文件夹拖到窗口内 |
| 系统打开方式 | 在访达 / 资源管理器中用墨阅打开 `.md`、`.markdown`、`.mdown`、`.mkd` |

侧边栏「文件」列出已打开的文档，可按文件名筛选；「大纲」列出当前文档标题，点按即可跳转，阅读时会自动高亮当前所在章节。

单篇文档上限 10 MB。支持 UTF-8、UTF-8 BOM、UTF-16 LE / BE，保存时保留原编码和原换行符（LF / CRLF）。

## 3. 三种视图

- **阅读**（⌘ / Ctrl + 1）：排版后的正文。
- **源码**（⌘ / Ctrl + 2）：编辑 Markdown 原文。标题、列表标记、代码、链接和强调会以不同颜色显示；超过约 15 万字符的文档，以及极长或包含异常连续反引号的单行，按纯文本显示，保证输入流畅。
- **分栏**（⌘ / Ctrl + 3）：默认左侧编辑、右侧实时预览，两侧按标题对齐同步滚动。工具栏的「交换左右分栏」可互换位置；设置中也可选择分栏顺序和左栏占比（20%—80%）。拖动中间分隔线调整宽度，双击恢复一半一半。顺序和比例会保留到下次打开。

双击窗口顶部空白处可放大或还原窗口。专注模式隐藏侧边栏与状态栏，按 Esc 退出。

## 4. 编辑

| 操作 | macOS | Windows |
| --- | --- | --- |
| 加粗 / 斜体 / 行内代码 | ⌘B / ⌘I / ⌘E | Ctrl+B / Ctrl+I / Ctrl+E |
| 插入链接 | ⌘K | Ctrl+K |
| 增加 / 减少缩进 | Tab / ⇧Tab（或 ⌘] / ⌘[） | Tab / Shift+Tab（或 Ctrl+] / Ctrl+[） |
| 续写列表或引用 | 在列表项末尾按 Enter；在空项上再按 Enter 结束列表 | 同左 |
| 查找 | ⌘F | Ctrl+F |
| 查找并替换 | ⌥⌘F | Ctrl+H |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Y |

再次对已加粗的选区按 ⌘B / Ctrl+B 会取消加粗。Tab 会把列表项嵌套到上一项之下，有序列表自动从 1 重新编号。

查找替换在源码中进行，按字面、不区分大小写；「全部替换」可一次撤销。

### 保存与保护

- ⌘ / Ctrl + S 保存，⇧⌘S / Ctrl+Shift+S 另存为；新建文档首次保存时选择位置。
- 切换文档或关闭窗口前若有未保存修改，会询问保存、放弃或取消。
- 保存先写入临时文件再替换原文件，中途失败不会损坏原文件。
- 若文件被其他程序修改：未编辑时墨阅会自动载入新内容；已编辑时会提示，并阻止保存覆盖他人的修改，可用「另存为」保留你的版本。

## 5. 支持的 Markdown

GitHub 风格表格、任务列表、删除线、自动链接；代码块高亮与一键复制；脚注、定义列表、缩写、上下标、==高亮==、Emoji；GitHub 提示块（`> [!NOTE]` 等）；KaTeX 数学公式（`$…$`、`$$…$$`）；Mermaid 流程图、时序图等；安全的原生 HTML（如 `<details>`、`<kbd>`）。

**图片**：支持 PNG、JPEG、GIF、WebP、AVIF 与安全的静态 SVG，路径相对于文档所在文件夹；单张不超过 20 MB，单篇文档图片预览合计不超过 32 MB。点按图片可放大。远程图片默认不加载，点按占位链接会在浏览器中打开。

**链接**：网页与邮件链接在系统浏览器 / 邮件程序中打开；指向其他 Markdown 的相对链接在墨阅中打开，但只能访问你已打开的文件夹范围内的文件。

## 6. 导出与打印

- 「文件 → 导出离线 HTML」：生成单个 HTML 文件，图片、公式字体、图表全部内嵌，可离线查看和发送（上限 28 MB）。
- 「文件 → 打印 / 存为 PDF」（⌘ / Ctrl + P）：使用系统打印，可在打印对话框中选择存为 PDF。纸张方向和边距请在系统打印预览中确认。
- **打印时附目录**（设置中勾选，默认关闭）：标题较多的文档会在正文前加一页目录，列出三级以内的标题。系统打印无法生成 PDF 书签，这页目录用于纸面查找。

## 7. 阅读设置

点按工具栏右侧「阅读设置」（⌘ / Ctrl + ,）：

- **阅读主题**：跟随系统、浅色、纸色、深色。
- **字号**：13–24，也可用「视图」菜单或 ⌘ / Ctrl + = / - / 0 调整。
- **正文宽度**：自适应、紧凑、舒适、宽阔。
- **界面语言**：跟随系统，或选择简体中文、繁體中文、English、日本語、한국어。菜单、对话框、提示与内置示例都会随之切换。
- **记住最近打开的文件**：默认关闭。开启后，侧边栏空白时会列出最近打开的 10 个文件或文件夹，点按即可重新打开；已移动或删除的项目会自动移出列表。关闭后立即清空。

墨阅只记住上述阅读偏好及窗口大小，不保存文档内容；只有开启「记住最近打开的文件」时才会保存文件与文件夹路径。

## 8. 常见问题

**打开文件夹后部分文件没有列出？** 隐藏文件夹（以 `.` 开头）、`node_modules`、`vendor` 以及符号链接会被跳过；超过 10 MB 或无法读取的文件会在提示中列出原因。

**图片不显示？** 新建且尚未保存的文档没有所在文件夹，请先保存；图片须位于已打开文件夹范围内。

**提示「文件已被其他程序修改」？** 为避免覆盖他人修改，保存被阻止。请用「另存为」保存当前内容，或重新打开文件后再合并修改。

**Windows 上无法启动？** 请确认已安装 Microsoft Edge WebView2 运行时。

**查看版本与许可？** macOS：「墨阅 MoRead → 关于墨阅与许可」；Windows：「帮助 → 关于墨阅与许可」。全部快捷键见「帮助 → 键盘快捷键」（⌘ / Ctrl + /）。

**有没有新版本？** 墨阅不会自动检查更新。在同一菜单选择「检查更新…」，或在关于窗口点按「检查更新」，会在浏览器中打开发布页面，与关于窗口里的版本号对照即可。

### macOS 窗口操作

- 红色关闭按钮或 ⌘W：关闭阅读窗口，应用继续运行，未保存修改保留在内存中；点击 Dock 图标或打开文档可重新显示。
- 黄色按钮或 ⌘M：最小化窗口。
- ⌘Q：退出应用，未保存内容会先询问保存或放弃。
- Mac 应用快捷键使用 Command，Control 保留给系统文本编辑。
