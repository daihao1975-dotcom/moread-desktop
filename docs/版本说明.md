# 墨阅 MoRead 1.0.2 版本说明

候选日期：2026-10-28 · 平台：macOS 12+（Apple 芯片）、Windows 10 / 11（64 位）

## 新增与优化

- **分栏布局**：源码与预览可左右互换，左栏占比可设为 20%—80%；支持拖动、键盘调整和双击居中，记住上次顺序与比例。
- **源码高亮**：按 Markdown 结构着色；保留原生编辑、撤销与输入法。修复未闭合标记导致的高亮卡顿，超长文档或异常长行自动按纯文本显示。
- **五种语言**：保留简体中文、繁體中文、English、日本語、한국어；界面、原生菜单与文件对话框同步切换，原有已移除语言设置自动回退。
- **最近打开**：可选记住最近文件与文件夹，默认关闭；关闭后清空记录。文件夹自动刷新，并保留临时无法读取的已有条目。
- **打印目录**：可选在打印或存为 PDF 时附目录页；新增手动打开发布页检查更新的入口。
- **可靠性**：设置读写错误可在关于页诊断中查看；补齐另存为、导出、分栏、高亮与文件夹刷新的回归测试；CI 增加 Windows 原生 Go 测试。

## 验证边界

- macOS 使用 Developer ID Application 正式签名，Apple 公证结果以随包验证记录为准；Windows 可执行文件尚未代码签名。
- 自动化测试、DOM 回归、构建与本机界面检查分别记录，不代表 Windows 实机验收或中文输入法完整实机验收。

# MoRead 1.0.2 Release Notes

Candidate date: 2026-10-28.

Swap source and preview panes, adjust the left pane from 20% to 80%, and remember the layout. Markdown source colouring preserves native editing and avoids stalls on malformed long lines. The interface now ships five languages: Simplified Chinese, Traditional Chinese, English, Japanese and Korean.

Optional recent files, folder refresh with temporary access-failure protection, a printed contents page, manual release-page checking, settings diagnostics and additional regression tests are included. Windows Go tests now also run in CI.

macOS packages use Developer ID Application signing; see the included verification record for notarization status. Windows packages remain unsigned. Automated tests and local interface checks do not establish Windows device or complete input-method acceptance.

# 墨阅 MoRead 1.0.1 版本说明

发布日期：2026-10-27 · 平台：macOS 12+（Apple 芯片）、Windows 10 / 11（64 位）

## 优化

- 打开文档时先显示安全渲染后的正文，随后补齐图片、公式、代码高亮与图表，避免可选组件阻塞正文。
- 代码高亮及语言组件改为按需加载，首屏脚本由约 495 KB 减至约 421 KB（未压缩）。
- 打开过程保留版本取消保护；后续补齐内容不强制回到页首；保存和导出仍使用完整内容。
- 「关于 → 高级诊断」提供最近一次打开的读取和绘制时间戳；仅保留内存内时间，不记录文档内容、名称或路径。

## 验证边界

- 打开耗时与设备、文档大小及图表复杂度有关；正文首次可读与全部图片、公式、图表完成分别计量。
- Windows 提供构建包；本次打开性能的实机计时范围为 macOS，不能代表 Windows 实机结果。
- 安装包未经 Apple 公证与 Windows 代码签名。

# MoRead 1.0.1 Release Notes

Released 2026-10-27.

Readable, sanitized document text is shown before optional images, math, syntax highlighting and diagrams finish. Syntax highlighting now loads on demand, reducing the initial uncompressed script from about 495 KB to 421 KB. Cancellation checks, edit baselines and complete exports are preserved. Advanced diagnostics show in-memory open/paint timestamps without document content or paths.

Opening performance depends on device and document complexity. macOS timing does not establish Windows device acceptance. Packages remain unnotarised on macOS and unsigned on Windows.

# 墨阅 MoRead 1.0.0 版本说明

发布日期：2026-10-26 · 平台：macOS 12+（Apple 芯片）、Windows 10 / 11（64 位）

## 新增

- **10 种界面语言**：简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português (Brasil)、Русский。界面、原生菜单（含 macOS「编辑」「窗口」菜单）、文件对话框、错误提示与内置示例同步切换，默认跟随系统。
- **查找并替换**：⌥⌘F / Ctrl+H，支持逐个替换与全部替换，全部替换可一次撤销。
- **Markdown 编辑辅助**：列表与引用回车续写、空项回车结束列表；Tab / ⇧Tab 按 CommonMark 规则嵌套列表并自动重编号；⌘B / ⌘I / ⌘E / ⌘K 加粗、斜体、行内代码、插入链接，均保留系统撤销。新增「格式」菜单。
- **外部修改检测**：文件被其他程序修改时，未编辑的文档自动载入新内容，已编辑的文档给出提示并阻止覆盖。
- **主题跟随系统**：新增「跟随系统」主题，随系统深浅色自动切换。
- **键盘快捷键面板**：「帮助 → 键盘快捷键」（⌘ / Ctrl + /）。
- **悬停提示**：所有工具按钮悬停或键盘聚焦时显示名称与快捷键。
- **字数与阅读时长**：状态栏按中日韩字符与西文单词统计字数，并估算阅读时长。
- **记住窗口大小**：下次启动恢复上次的窗口尺寸与最大化状态。
- macOS 应用菜单补齐「隐藏其他」「全部显示」。

## 优化

- 首屏脚本体积由约 1.2 MB 降至约 0.5 MB：数学公式组件与字体仅在文档含公式时加载；不含公式的文档导出 HTML 体积相应减少约 0.6 MB。
- 大文档输入时按篇幅自适应延迟重绘，减少卡顿。
- 源码视图查找时按实际换行位置精确滚动到匹配处。
- 应用图标重新设计，适配 macOS 26 及以上系统图标规范，在程序坞与访达中完整铺满显示。
- 深色系统下启动不再出现浅色闪屏。

## 已知事项

- 安装包未经 Apple 公证与 Windows 代码签名，首次打开需按《使用手册》第 1 节确认一次。
- Windows 版需要 Microsoft Edge WebView2 运行时。

# MoRead 1.0.0 Release Notes

Released 2026-10-26 · macOS 12+ (Apple silicon), Windows 10 / 11 (64-bit)

**New**: interface in 10 languages, including native menus, dialogs and messages; find and replace; Markdown editing aids (list continuation, CommonMark-correct Tab nesting, ⌘B / ⌘I / ⌘E / ⌘K) with native undo and a new Format menu; detection of changes made by other programs; a System theme; a keyboard shortcuts panel; hover hints on every toolbar button; word count and reading time; remembered window size; Hide Others and Show All in the macOS app menu.

**Improved**: the first-screen script shrinks from about 1.2 MB to 0.5 MB because math support loads only when needed, which also makes HTML exports without math about 0.6 MB smaller; adaptive re-rendering for large documents; exact scrolling to find results in the source view; a redesigned icon that fills the macOS 26 icon shape; no light flash when starting in dark mode.

**Known**: packages are not notarised by Apple or code-signed for Windows, so the first launch needs one confirmation (see the User Guide, section 1). Windows requires Microsoft Edge WebView2 Runtime.
